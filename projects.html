Reliable Lead Automation

n8n · Make · Zapier

An importable n8n workflow: capture a lead, de-duplicate it, qualify it with an AI step, write it to the CRM, alert sales — built so leads never silently disappear.

  • De-dupe before anything else — a 30-day idempotency key stops double outreach.
  • The AI step is schema-checked, not trusted — a bad model reply is downgraded and flagged for review, never written as garbage.
  • Idempotent CRM write + retries — a retry after a partial success makes one contact, not two.
  • Failures degrade, don't cascade — a Redis or Slack blip can't block a qualified lead.

Citation-Grounded RAG

RAG · retrieval · eval

A complete RAG project built on one rule: if no source clears the relevance floor, the system refuses to answer instead of inventing a confident, uncited one.

  • Score-floor retrieval — the retriever is allowed to return nothing.
  • Grounded or refuse — every answer is cited, or it's an honest "I don't have that."
  • Measured, not vibed — answerability and citation validity scored on a gold set.
  • Regression gate — a config change ships only if neither metric drops.

Support Agent that Deflects — Safely

agents · guardrails

An end-to-end support agent where every risky action is blocked in code, so it can actually face customers: grounded answers, injection defense, scoped tools, human sign-off on money.

  • Grounded or escalate — answers from the KB with a citation, or hands off; never invents policy.
  • Injection defense — user text and tool output are both scanned; a flagged message runs no tools.
  • Scoped tools — reading an order is allowed; issuing a refund needs a scope the default agent lacks.
  • Human approval on money — refunds are queued for a teammate, never auto-executed. PII redacted on the way out.
